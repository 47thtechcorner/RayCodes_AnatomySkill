# ⚙️ Anatomy Skill Builder

Transform technical concepts into interactive, physical mechanical machines rendered directly as standalone browser-ready HTML files.

| Step 1: Input | Step 2: AI Action | Step 3: Result |
| :--- | :--- | :--- |
| Enter mechanical or code prompt | Builds isometric SVG & 3D models | Standalone interactive HTML page |

---

## ⚡ Quickstart

### Step 1: Verify or Install Node.js (Requires 20.10+)

Check if Node.js is already installed:

```powershell
node -v
```

> **Voiceover:** The system does require a recent modern Node.js environment (version 20.10 or later) to run the drawing engine and geometric checks.

*(Optional)* If you don't have Node.js 20.10+ installed, install the latest LTS release on Windows using winget:

```powershell
winget install OpenJS.NodeJS.LTS
```

Alternatively, download and run the installer directly from [nodejs.org](https://nodejs.org).

### Step 2: Install Anatomy Skill for Antigravity

Install the Anatomy skill globally with one command:

```powershell
npx skills add wheresryan22/anatomy -g -a antigravity
```

## 🎯 Antigravity One-Liner Prompts

Paste any of these commands directly into Antigravity to generate interactive, browser-ready HTML files of real-life mechanical objects:

1. **/anatomy Mechanical Metronome (Light Theme)**
   ```text
   /anatomy explain how a mechanical metronome works with its swinging pendulum and sliding weight. Build it as an interactive standalone HTML page, light theme.
   ```
2. **/anatomy Combination Padlock (Dark Theme)**
   ```text
   /anatomy explain how a classic combination padlock works with its internal cam and pins. Build it as an interactive standalone HTML page, dark theme.
   ```
3. **/anatomy Manual Burr Coffee Grinder (Light Theme)**
   ```text
   /anatomy explain how a manual burr coffee grinder works, showing the beans feeding into the conical burrs when the handle turns. Build it as an interactive standalone HTML page, light theme.
   ```
4. **/anatomy Mechanical Music Box (Dark Theme)**
   ```text
   /anatomy explain how a mechanical music box cylinder and tuned comb work together to pluck notes. Build it as an interactive standalone HTML page, dark theme.
   ```
5. **/anatomy Camera Lens Aperture (Light Theme)**
   ```text
   /anatomy explain how a camera lens aperture mechanism works with its overlapping sliding blades. Build it as an interactive standalone HTML page, light theme.
   ```

## 💡 Practical Use Cases

1. **Software Architecture:** Explain caching layers as pin-tumbler locks and rate limits as calibrated water buckets.

4. **Hardware Prototypes:** Visualize 3D mechanical linkages and rotation assemblies directly in the browser.
5. **Technical Presentations:** Showcase engineering principles with tactile sliders and draggable components during live demos.
